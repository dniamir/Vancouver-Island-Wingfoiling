# Vancouver Island Wingfoiling

This repository contains data and tools for processing Vancouver Island wingfoiling GPS tracks.

## Contents
- `Data/`: Contains HTML and CSV data files.
- `Commands/`: Scripts for environment setup and data processing.
- `extract_html_data.py`: Script to extract data from HTML files.
- `plot.ipynb`: Jupyter notebook for visualizing the data.

## Setup
Use the scripts in the `Commands/` folder to set up your environment.
